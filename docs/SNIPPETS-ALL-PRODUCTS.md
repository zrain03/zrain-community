# Community code snippets for existing Zrain products

Each product has a permanent, independent community ID. Copy the correct snippet into that product website.
Do not paste developer API keys into public HTML.

## Usage

1. Find the product in the list below.
2. Paste its snippet into the actual public product HTML near the end, before `</body>`.
3. Publish the product website using its own deployment process.
4. Verify its comments are separate from every other product.

**Note:** This file is a reference only. It does not modify or deploy the other 57 projects.
