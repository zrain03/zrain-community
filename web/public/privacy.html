ZRAIN COMMUNITY

Privacy & data use.

How Zrain Community handles information when you participate or request developer access.

Public comments

Display name, comment text, category, time and public status are published immediately if they pass automated checks. A display name is optional; you do not need to register an account. Do not include private information in a public comment.

Abuse prevention

Cloudflare Turnstile verifies submissions. The API creates a short-lived daily keyed hash for rate limits rather than storing raw visitor IP addresses in the comments database. Hosting, Cloudflare, and your browser may separately process technical connection data under their own services.

Comment control and retention

A private per-comment key allows edit or delete for 24 hours. The browser saves up to five unexpired comment keys locally on the Zrain Community site so you can manage your comments after refresh on the same browser, if storage is permitted. Clearing site data, private browsing, or storage restrictions can remove this access. Anyone with access to these browser keys can manage those comments until they expire. Edits passing the same automated checks appear immediately. Moderators may delete inappropriate posts. Published comments otherwise remain until removed by moderation or a valid removal request.

Developer applications

When applying for developer access, your name, contact email, project, website, and verification proof are stored for approval and account support. They are not shown publicly. Please contact Zrain to correct or request removal of your application details.

Contact

For data requests, email zrain.dev@gmail.com. Do not send private tokens or passwords.

This is an informational statement about the current system, not a claim of independently audited compliance with any particular law.
